# Desktop Clients

ShapeDiver Apps can interact with so-called "Desktop Clients", allowing to send and receive geometry from local software environments in real-time. So far, Rhino and Adobe Illustrator are supported as desktlop clients, as well as some custom integratiosn with industry-specific software. Get in touch if you would like us to support other desktop clients.
